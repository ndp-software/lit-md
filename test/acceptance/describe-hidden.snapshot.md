# Describe Hidden Format

When using `--describe=hidden`, describe() block names are omitted from output (default behavior).

## Basic describe with examples



```ts
1 + 1 // => 2

2 * 3 // => 6
```

## Nested describes



Some description about the outer group



```ts
5 - 2 // => 3
```



```ts
10 / 2 // => 5
```

## Deeply nested describes







```ts
typeof 'test' // => 'string'
```
